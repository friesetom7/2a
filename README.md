# Nemos Spielplatz

Lernspiel für die Klasse 2a mit Hai Nemo: https://friesetom7.github.io/2a/

- Nomen-Inseln
- Lernwörter-Inseln
- Leuchtturm-Insel (der, die, das)
- Lese-Lagune
- Rechtschreib-Inseln (doppelte Mitlaute, ck, tz, ie, Verlängern, Ableiten, Sp/St, V-Wörter, -er, Satzzeichen)
- Adjektiv-Inseln (folgen)

Jede Insel hat drei Stufen (leicht, mittel, schwer), jedes Kapitel eine Schatzinsel und eine Experten-Insel.
Das Spiel startet jedes Mal bei 0 und speichert keine Daten der Spieler.
